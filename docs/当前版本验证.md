# 当前版本验证

本地解释器为Python3.9，PyTorch2.0.1+cu117、Transformers4.40.2，RTX3050Ti4GB；目标正式协议为Python3.11、Torch2.8.0+cu128、Transformers4.40.2及PEFT0.10.0。未更改主机环境或安装依赖。

35项单元契约通过，覆盖旧入口19项与新入口16项。main/base使用真实GPT2和Taxi266输入，与研究原件逐位核对初始化状态、更新标记、构造RNG、确定性输出、采样输出和训练RNG。

真实数据GPU短测通过main/base/官方ST-LLM+×Taxi/Bicycle两种节点规模，共6个单元，batch20，含前向、反向、Ranger更新和同步。迁移另通过Taxi正向与Bicycle反向两条三阶段流水线，目标260支持，七项配对守卫全部通过，源和短测均无测试评估。

Windows本地安装的非必要bitsandbytes量化扩展无法导入，本地验证进程将其排除；官方模型使用标准浮点PEFT LoRA，不依赖量化扩展，未改变算子、精度、batch或cuDNN设置。推荐在干净环境安装列明依赖，无需安装bitsandbytes。

独立正式收集读取冻结campaign签名，避免旧代码结果覆盖新版本结果。任务身份、三个阶段文件、支持、预算、优化器和七项实际配对记录会复检。对错误身份、跨签名、缺件和不实配对声明已有回归用例。

本次没有在5090/4090重新跑完整60单元和60迁移阶段。仓库的参考结果来自已完成论文实验，本地短测不作为论文性能证据。
