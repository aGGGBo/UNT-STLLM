# 版本0.1.0的验证范围

本版本复现Table II中UNT-STLLM主模型的固定协议。验证分为单元契约、原实现对照、真实资产与GPU短测，以及完整正式重跑；各层级不能相互替代。

## 本地已经验证的内容

19项单元测试通过，覆盖数据尾批填充与打乱、仅训练数据拟合scaler、正值标签掩码和逐预测步指标、模型输出与梯度边界、验证平台期恢复、Ranger多步、日志状态、损坏结果处理、分批与跨任务签名、续跑结果选择、WAPE单位及命令行失败状态。

原实现对照使用相同的本地GPT2-small、真实Taxi266输入及相同随机种子。初始化参数、可训练标志、构造后的随机状态、确定性推理、训练采样和KL逐值一致；损失、裁剪后及梯度中心化后的梯度、一次参数更新一致。Ranger另经18步对照，覆盖梯度中心化、RAdam整流和Lookahead。

本地真实数据短测在RTX 3050 Ti 4GB上以batch20、种子2026验证四项任务，覆盖266和250两种节点规模，包含模型前向、反向、优化器更新、CUDA同步和验证预测。短测不读取test，不生成表II正式性能结果。

本地验证环境为Python 3.9、PyTorch 2.0.1+cu117、Transformers 4.40.2和NumPy 1.26.4。原正式实验环境主要为Python 3.11、PyTorch 2.5.1+cu121、Transformers 4.40.2和NumPy 2.1.2，推荐复现环境见依赖与复现指南。不同硬件、CUDA和软件版本可能带来浮点差异。

## 独立交付检查

代码包已在独立空目录解包，19项测试、14项真实资产检查和四任务batch20 GPU短测通过。缺失20个正式单元时，汇总按预期返回退出码2；缺失14项资产时，检查一次列出全部问题并返回退出码1。另以明确标记的合成结果验证20单元齐全时的汇总与百分数换算，该合成用例不代表模型性能。检查排除了对原研究项目目录中未分发模块的依赖，结果文件保留在本地交付记录中，不随代码分发训练日志或数据。

## 完整复现与远程验证

本次代码整理没有重新执行四任务、每任务五种子、每种子250轮的全部正式训练。`configs/reference_metrics.json`保存的是论文所对应的历史五种子参考数值，不是此次代码短测生成的结果。

本次整理没有连接用户的远程GPU主机执行实验。目标主机需要按复现指南依次通过资产检查、正式batch短测和完整训练。短测成功代表该主机可以执行所覆盖的运算，正式结果需要以全部20个成功单元及`table2_complete=true`的汇总为准。
