# 数据与代码可用性

本仓库提供论文表II中UNT-STLLM主模型的复现代码、固定配置、指标计算和结果汇总。实验范围为NYCTaxi与CHBike的pick-up、drop-off四项任务，每项任务五个种子。

## 数据来源

预处理NYCTaxi与CHBike数据来自[STLLM+官方仓库](https://github.com/CoArrayLiu/STLLMPlus)提供的[数据共享目录](https://drive.google.com/drive/folders/1iif59LObrPu-QrpL8Y6lWeajbn_gRf7v?usp=drive_link)。四项任务的文件布局、输入通道及资产复制方法见[复现指南](复现指南.md)。

`configs/assets.json`记录每个文件的大小与SHA256。下载或复制后运行`python run.py check`核对完整性，保留原始预处理窗口及train、val、test划分。数据的使用和再分发遵循原提供者的条款，仓库不重新分发这些文件。

## 代码与预训练模型

代码及复现说明可在[UNT-STLLM](https://github.com/aGGGBo/UNT-STLLM)获取。GPT2-small从本地目录加载，所需文件见资产清单；模型权重不包含在代码仓库中。

`configs/reference_metrics.json`保存论文参考结果。新的复现实验通过`run.py train`生成各次运行的结果，再由`run.py summary`汇总，实验输出不随代码分发。
