# 数据与代码可用性

## 论文应写什么

建议论文明确交代数据来源和代码获取状态。数据可用性说明能让读者定位同一份预处理数据；代码可用性说明应区分当前私人保管与日后公开。不能把私人GitHub链接描述为读者已经可以访问的公开代码。

IEEE TKDE的[官方征稿说明](https://www.computer.org/digital-library/journals/tk/cfp-ieee-transactions-on-knowledge-data-engineering)鼓励共享数据并提供相关复现支持。该说明不等于所有稿件都必须在投稿时将代码公开。具体提交要求应以投稿系统和当期作者指南为准，不能将其他IEEE期刊的强制政策直接套用到TKDE。

## 数据入口

四项任务使用[STLLM+官方仓库](https://github.com/CoArrayLiu/STLLMPlus)分享的预处理NYCTaxi与CHBike数据，[共享目录](https://drive.google.com/drive/folders/1iif59LObrPu-QrpL8Y6lWeajbn_gRf7v?usp=drive_link)中的文件应与`configs/assets.json`的大小和SHA256一致。仓库不重新分发这些数据，不根据test结果调整数据划分。数据的使用和再分发权限以原始数据提供者的条款为准。

下面是适用于当前四交通任务范围的英文数据声明草稿。论文其他实验若使用额外数据集，完整数据声明还需要补齐对应入口。

> The preprocessed NYCTaxi and CHBike datasets used for the four traffic forecasting tasks are available through the official STLLM+ repository (https://github.com/CoArrayLiu/STLLMPlus). File hashes and the expected input format are documented in the reproduction repository.

当前仓库为私人状态，读者不能查看其中的指纹清单。因此投稿时若仓库仍未开放，应把上一段末句删除，或在可供读者访问的材料中提供同一清单。

## 当前代码状态

复现代码位于`https://github.com/aGGGBo/UNT-STLLM`，当前为个人私人仓库，提供Table II中UNT-STLLM一行的四任务五种子复现。没有公开访问权限，不承诺尚未确定的开放日期，也不把访问请求写成已经建立的代码交付机制。

仅描述当前事实的英文草稿如下。它可用于内部稿件，正式投稿时应根据实际可获取方式调整。

> The implementation and reproduction instructions for the UNT-STLLM results in Table II are maintained in a private repository. The repository is not publicly accessible at present.

如果作者决定在投稿前或发表时公开仓库，可以在公开成功后改为下文，不能提前使用。

> The implementation and reproduction instructions for the UNT-STLLM results in Table II are available at https://github.com/aGGGBo/UNT-STLLM. The repository includes the fixed configurations and evaluation scripts for the four traffic forecasting tasks.

这份仓库不覆盖论文的全部实验。公开声明应维持Table II主模型的准确范围，不能泛称所有实验均可由本仓库复现。私人状态的变更需要作者另行决定。
