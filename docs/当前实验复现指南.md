# 当前实验复现指南

本版本与旧3090协议独立。默认250轮、20批、12步输入/输出、五个固定种子。完整命令与环境以根README为准。

## 不变的计算

main/base与研究构造的初始化张量、可训练标记、构造后RNG、推理和训练采样均已逐位核对。基类共享日历、身份、观测、门控、变分与预测头。main冻结所有原GPT-2参数并加顶部两层rank8/alpha16 LoRA，关系置于softmax前且节点双向访问；base直接更新既定原参数，采用因果访问与softmax后关系残差。实际接收梯度数按反向记录，未使用的词嵌入不当成有效更新预算。

损失为正值标签上的MAE、0.024倍沿预测时间的幅度谱MAE，以及模型内0.001倍KL乘以50轮退火至0.001的系数，最终有效上限1e-6。验证分数等权平均包含尾批填充的批次MAE；测试去除填充，并按12视界分别计分后平均。Ranger包含梯度中心化、RAdam及Lookahead。12轮平台期恢复验证最佳权重并减半学习率，优化器状态保留。

## 初始化迁移

每阶段重置相同种子。固定支持由局部default_rng选择排序索引，不消耗全局训练RNG。源状态在其验证最优模型恢复后复制。目标节点嵌入及静态关系保留目标初始值，其余共享参数与兼容缓冲区严格复制。复制前完整检查键、形状、dtype及有限值，检查失败不留下部分迁移。

新代码记录两目标的支持索引/scaler、节点初值、共享初值、RNG、批次哈希、更新次数，以及源快照对应关系。正式收集不接受短测，不混合source与目标阶段，不以重复attempt充当额外种子。

## 运行资产

代码默认仅访问本地GPT2。数据来自STLLM+提供的NPZ与邻接文件；这些文件不随源码分发。新资产`configs/matched_assets.json`登记官方邻接，其他资产沿用`configs/assets.json`。检查失败必须先解决，不能以替换成随机权重或合成数据继续正式运行。

旧入口run.py和其原配置用于原主模型协议。完整60单元比较和20流水线迁移需在目标主机正式运行，短测通过不代表已经复算出论文分数。
